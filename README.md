# Hi, I'm Manas Reddy Arumalla 👋

I build **autonomy for robots** — state estimation and safe control for aerial, mobile, and manipulation platforms. My work puts classical, optimal, and learned methods on the **same benchmark** and reports what actually wins, including the negative results — mostly in high-fidelity simulation (MuJoCo, Gazebo, ROS 2, PX4 SITL), with real-hardware roots (Arduino/Raspberry Pi robots, e-Yantra national robotics competition).
